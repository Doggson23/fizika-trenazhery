Сложение сил: проекции

Равнодействующая сил на одной прямой и на плоскости. Клетка — 10 Н, если в задаче не сказано иначе. Силы приложены к одной точке.

F1 F2 F3 равнодействующая R проекции (пунктир)

Что нужно знать

Сила — векторная величина: у неё есть модуль (сколько ньютонов), направление и точка приложения. На рисунке сила — стрелка.

Равнодействующая R — одна сила, которая действует на тело так же, как все приложенные силы вместе. Найти равнодействующую — значит сложить силы как векторы.

Проекция силы на ось. Выберите ось (например, x вправо). Проекция Fx — это «тень» стрелки на оси: число со знаком. Если стрелка смотрит по оси — проекция положительная, против оси — отрицательная, перпендикулярно оси — нулевая. На клетчатом поле проекция — это просто число клеток вдоль оси, со знаком.
Силы на одной прямой. Направьте ось вдоль прямой. Проекция равнодействующей — сумма проекций: Rx = F1x + F2x + … Знак Rx говорит, куда направлена R; модуль R = |Rx|.
Пример: F1 = 50 Н вправо, F2 = 30 Н влево: Rx = +50 + (−30) = +20 Н — 20 Н вправо. Силы в одну сторону складываются, навстречу — вычитаются (из большей меньшую), а R смотрит туда же, куда большая.
Силы на плоскости. Две оси: x и y. Считаем две суммы: Rx = F1x + F2x + … и Ry = F1y + F2y + … Модуль — по теореме Пифагора: R = √(Rx² + Ry²). Направление: стрелка из начала в точку (Rx; Ry); угол с осью x находят из tg α = Ry / Rx.
Если сила дана модулем и углом α к оси x: Fx = F·cos α, Fy = F·sin α. Проверка: при α = 0° вся сила «ложится» на ось x, при α = 90° — на ось y. Частный случай — две перпендикулярные силы: R = √(F1² + F2²) (диагональ прямоугольника, стороны 3 и 4 → диагональ 5).

Геометрически то же самое — правило параллелограмма: отложите обе силы из одной точки, достройте до параллелограмма, его диагональ из этой точки и есть R. На рисунке справа (или сверху на телефоне) параллелограмм показан пунктиром — подвигайте силы на вкладке «Плоскость» и проверьте.

Порядок действий в любой задаче: 1) выбрать оси (одну или две); 2) для каждой силы записать проекции со знаком; 3) сложить проекции по каждой оси → Rx, Ry; 4) R = √(Rx² + Ry²); куда смотрит — по знакам Rx, Ry. Если Rx = 0 и Ry = 0 — силы скомпенсированы, R = 0: тело покоится или движется равномерно и прямолинейно.
